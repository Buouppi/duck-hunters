# 🦆 Ducks Hunter

A premium party mini-game website where players scan QR codes on physical rubber ducks to reveal secret collectible cards.

## 🚀 Quick Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `ducks-hunter`)
2. Upload all files maintaining the folder structure:
   ```
   /
   ├── index.html
   ├── style.css
   ├── script.js
   ├── infozigan.html
   ├── pastuh.html
   ├── zlodei.html
   ├── someliee.html
   ├── toksik.html
   ├── polit.html
   ├── priority.html
   ├── holy.html
   ├── chaotic.html
   └── cards/
       ├── proklatie.png     ← cursed card back
       ├── golden.png        ← golden card back
       ├── Infozigan.png
       ├── Pastuh.png
       ├── skasochnui-zlodeii.png
       ├── someliee.png
       ├── toksik-kouch.png
       ├── polit-doll.png
       ├── priority.png
       ├── holy.png
       └── chaotic.png
3. Go to Settings → Pages → Source: Deploy from branch → main → / (root)
4. Your site will be live at `https://yourusername.github.io/ducks-hunter/`

## 🎨 Card Themes

- **Gold cards** (golden.png back): Pastuh, Someliee, Priority, Holy
- **Cursed cards** (proklatie.png back): Infozigan, Zlodei, Toksik, Polit, Chaotic

## 🃏 How to Play

1. Hide rubber ducks with QR codes around the venue
2. Players scan QR codes with their phones
3. A mysterious card back appears with a floating animation
4. Tap the card to flip it and reveal the duck character
5. Golden ducks = good luck, Cursed ducks = challenges!
